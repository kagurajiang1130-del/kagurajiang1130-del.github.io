# 报价、交付、回款与风险控制 SOP

## 报价单必须写清楚

每份报价至少包含：

1. 客户要解决的具体问题；
2. 工作范围；
3. 可验收交付物及格式；
4. 客户必须提供的材料、权限和确认人；
5. 时间表与双方反馈时限；
6. 包含的修改轮次与超出后的计价方式；
7. 外部费用、平台费用、差旅和税费由谁承担；
8. 订金、阶段款、尾款、退款和逾期条件；
9. 账号、原始文件、翻译记忆、素材和最终成果的归属；
10. 明确不包含事项；
11. 不保证流量、排名、粉丝、到店或销售结果；
12. 报价有效期和启动条件。

## 默认的范围控制

- 一个项目只有一个最终确认人；
- 反馈应一次性汇总，零散追加视为新一轮；
- 新渠道、新语言、新页面、新素材制作或新增账号不自动包含；
- 客户材料迟交会顺延时间；
- 平台审核、认证、封禁和算法变化不由服务方保证；
- 涉及食品、医疗、法律、过敏、价格、支付和取消规则的内容必须由客户确认事实；
- 未获得书面授权，不公开客户名称、Logo、数据、截图或项目成果。

具体修改轮次、付款比例和交付周期必须在每份报价里填写，不使用无限修改。

## 启动条件

只有同时满足以下条件才排期：

- 范围、交付物和不包含事项已确认；
- 合同或书面委托已确认；
- 约定订金真实到账；
- 必要材料、账号权限和确认人已到位；
- 项目编号已建立；
- 现金流水和项目表已创建对应记录。

## 交付过程

### 1. 材料接收

建立材料清单，标记来源、版本、是否可公开及客户确认人。不要从旧网页或第三方评论推断关键经营规则。

### 2. 内容与体验分析

区分：事实信息、文化背景、操作指引、平台表达和营销表达。对不确定项列问题，不自行补成确定事实。

### 3. 制作与内部检查

至少检查姓名/店名、数字、价格、日期、地址、营业时间、支付、预约、取消、过敏和禁止事项。三语言版本不能仅靠机器翻译后直接交付。

### 4. 客户确认

提供明确版本号和截止日。客户的事实确认与语言偏好修改分开记录。

### 5. 验收与发布

按报价中的验收清单交付。平台发布前再确认账号、权限、素材授权和发布时间。

### 6. 结项

记录尾款、实际工时、实际成本、返工原因、客户反馈和证据公开授权。没有授权的成果不得放入网站案例。

## 变更单触发条件

发生以下任一情况，应暂停原任务并书面确认变更：

- 新增渠道、语言、页面、账号或素材类型；
- 修改已确认的经营事实或品牌方向；
- 客户更换最终决策人；
- 超过约定修改轮次；
- 客户迟交材料导致需要重新排期；
- 平台或第三方要求新增工作；
- 原报价依赖条件不再成立。

变更单写明新增范围、费用、周期和对原交付的影响。未确认前不继续扩展工作。

## 现金控制

- 所有收付款按真实日期进入“现金流水”；
- 收入状态只用“已到账”，不能用“已承诺”代替；
- 成本必须保留发票、收据、转账或其他凭证；
- 项目应收款每周检查；
- 逾期后按合同执行提醒、暂停或终止，不继续无上限垫工时；
- 外币按统一、可说明的换算规则记录，并保留原币金额。

## 高风险信号与处理

| 信号 | 处理 |
| --- | --- |
| 要求保证曝光、粉丝、到店或销售 | 书面澄清不可保证；无法接受则停止 |
| 要求免费完成完整方案或样稿 | 只提供范围说明，转为付费诊断 |
| 无法确认账号或素材权利 | 暂停账号与发布工作 |
| 多名人员分别下指令 | 要求指定唯一确认人 |
| 拒绝订金、合同或范围 | 不排期 |
| 关键经营信息反复变化 | 暂停并触发变更单 |
| 要求虚构评价、经历或本地身份 | 拒绝并停止相关工作 |
| 项目贡献率低于内部底线 | 缩小范围、提价或放弃 |

## 专业事项

这份 SOP 是经营控制文件，不替代日本或中国适用的律师、税务师、行政书士、劳动专业人士或平台官方意见。涉及经营主体、跨境收款、税务、商标、个人信息和广告合规时，应按实际情况获得专业确认。
