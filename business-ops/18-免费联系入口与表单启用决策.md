# 免费联系入口与表单启用决策

## 当前决定

- **记录日期**：2026-08-22；
- **当前启用状态**：网站联系表单保持禁用，价格卡、占位邮箱、占位 SNS 和 Privacy Policy 不提供假链接；
- **最短免费上线方式**：创始人确认真实公开邮箱后，先启用 `mailto:` 邮箱入口，不把咨询内容交给新的第三方表单平台保存；
- **表单候选**：需要表单时，Formspree 作为第一候选；建立账号、接受条款、发布隐私说明和接通收件邮箱都必须另行获得创始人批准；
- **中国大陆边界**：没有任何候选平台的官方证据证明其表单端点在中国大陆不同城市和运营商都稳定可用，启用前必须用目标网络提交测试。

这项决定不阻止网站公开预览。它只阻止在没有真实收件人、隐私说明和可验证表单端点时收集姓名、邮箱、店铺信息与留言。

## 启用 `mailto:` 前的硬门

以下全部满足后，才把占位邮箱改为可点击链接：

- [ ] 创始人明确批准该邮箱公开展示；
- [ ] 邮箱可以真实收信并已启用双重验证；
- [ ] 已确定一个工作日内的查看与回复负责人；
- [ ] 网站不把表单界面描述成已经能够发送；
- [ ] 邮件地址、品牌名和公开身份一致，不使用未经确认的团队或公司身份。

## 启用第三方表单前的硬门

除上述邮箱门外，还必须满足：

- [ ] 创始人批准具体服务商、账号建立和条款接受；
- [ ] 只收集姓名、店铺/公司、回复邮箱、公开网站/SNS、咨询方向和留言；
- [ ] 不收集密码、支付信息、身份证件、健康信息或游客个人资料；
- [ ] 发布真实 Privacy Policy，说明处理目的、服务商、保留、删除与联系办法；
- [ ] 设置垃圾过滤和来源域名限制；
- [ ] 在日本和目标中国网络各完成一次真实提交、通知、回复和删除测试；
- [ ] `siteSettings.contactFormAction` 只填官方账号生成的 HTTPS 端点，不把密钥或后台凭证写进仓库；
- [ ] 免费层达到 70% 时预警，未经批准不自动升级或产生超额费用。

## 停止条件

出现以下任一情况，立即重新禁用表单：

- 提交成功但收件人没有收到通知；
- 中国目标网络反复无法提交；
- 垃圾提交超过人工处理能力；
- 服务商条款、免费额度、数据用途或保留发生重大变化；
- 无法满足删除请求、隐私说明或访问控制；
- 发生未经批准的收费、超额或账户风险。
