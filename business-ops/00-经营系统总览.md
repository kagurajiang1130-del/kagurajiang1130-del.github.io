# 澜顷经营系统总览

## 目标与口径

经营目标是：在 2026-12-31 前，以真实到账收入减去实际支付业务成本为口径，力争累计净利润达到人民币 100,000 元。

这不是结果保证。签约额、报价额、开票额、应收款和媒体曝光都不能代替真实到账；未记录的成本和创始人工时会单独暴露，避免出现“账面赚钱、实际亏工时”。

经营数字统一进入《澜顷_经营与利润管理台账_v0.1.xlsx》，不要在多个文件中维护互相冲突的版本。

## 一条经营主线

```text
目标客户名单
→ 真实问题访谈
→ 合格线索
→ 有边界的付费测试
→ 正式报价与订金
→ 按范围交付
→ 验收与尾款
→ 复盘真实工时、成本与证据
→ 决定继续、提价、缩小或停止
```

## 四道门

### 1. 需求门

在写正式套餐前，先完成至少 10 次真实目标客户沟通，确认问题、现有做法、决策人、预算条件和购买触发点。不能把“对方觉得有意思”当成购买证据。

### 2. 报价门

每次报价前必须明确：工作内容、交付物、客户输入、修改轮次、周期、外部费用、知识产权、平台责任、验收标准和明确不包含的事项。

### 3. 现金门

默认先收到合同约定的订金再排期。只有到账的收入进入目标口径；支付状态和凭证链接进入“现金流水”。

### 4. 复盘门

每个项目结束后记录实际工时、直接成本、获客成本、现金利润、全成本利润、返工原因和是否获得证据公开授权。没有真实数据，不扩张套餐和投放。

## 每周固定动作

### 周一：销售与产能计划

- 检查剩余目标、剩余周数与本周可投入工时；
- 选出本周最重要的 10 个目标商家；
- 为每条线索设置唯一的下一动作和日期；
- 只接受当前产能可以交付的承诺。

### 周三：漏斗与阻塞检查

- 查找没有决策人、没有问题、没有下一动作的线索；
- 检查已发报价是否缺范围、成本或有效期；
- 检查进行中项目是否等待客户材料或发生范围扩大。

### 周五：现金与学习结账

- 录入本周所有真实收付款；
- 对账凭证，不用聊天记录代替到账；
- 更新项目工时和成本；
- 写下本周一个被验证的事实、一个被否定的假设和下周一个实验。

## 文件分工

| 文件 | 作用 |
| --- | --- |
| `app/content.ts` | 已批准后才能进入的三语公开网站内容 |
| `content-workflow/` | 网站逐 Part 研究、访谈、审批与母稿 |
| `business-ops/` | 内部获客、报价、交付、回款与风险程序 |
| `CONTENT_GUIDE.md` | 修改网站文字、图片和重新发布 |
| 经营台账 Excel | 唯一经营数字与周度看板 |

## 不得跨越的边界

- 不虚构客户、案例、团队、评价、经历或业绩；
- 不承诺流量、排名、粉丝、到店人数或销售结果；
- 不替客户伪造身份、材料、平台资质或用户反馈；
- 不在没有范围和付款条件时开始完整制作；
- 未经明确批准，不产生债务、大额支出、长期合同或对外承诺；
- 商标、税务、劳动、合同和平台规则问题交由适用地区的专业人士确认。
