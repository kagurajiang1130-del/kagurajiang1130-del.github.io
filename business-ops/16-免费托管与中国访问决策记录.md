# 免费托管与中国访问决策记录

## 决策状态（2026-08-22）

- **现有公开基线**：保留 `https://kagurajiang1130-del.github.io/`，继续作为免费、公开、HTTPS 的对照入口；本轮不迁移、不下线。
- **条件式首选实验**：Tencent EdgeOne Pages（Makers）是下一步优先验证的镜像候选，但它不是“零条件即可在中国大陆稳定访问”的答案。
- **首选成立条件**：有可用自定义域名；能在控制台获得所需服务区域；若选择中国大陆或含中国大陆的全球加速，还须满足 ICP 备案、实名与主体一致性要求；最后必须通过真实中国大陆网络测试。
- **仍未证明的事项**：当前没有证据证明任何免费平台在中国大陆各城市、运营商和终端都稳定可用。
- **发布边界**：本轮只更新内部决策文档，不创建云项目、不绑定域名、不部署镜像、不修改公开网站。Draft PR 中的新版仍不得合并或发布，直到用户明确回复：`确认公开发布新版`。

这是一项可逆决策。EdgeOne 实验失败、免费政策变化或合规条件不成立时，GitHub Pages 仍是可回退基线。

## 三种“可访问”不得混为一谈

| 证据等级 | 含义 | 目前状态 |
| --- | --- | --- |
| 海外公开访问 | 海外执行环境可以通过 HTTPS 打开网站 | GitHub Pages 已有当前环境 HTTP 200 记录 |
| 中国大陆跨境访问 | 大陆用户经跨境链路可以打开海外节点 | 未完成足量真实测试，不能承诺稳定 |
| 中国大陆境内 CDN / 稳定候选 | 内容通过境内节点提供，且备案、实名、域名与主体条件成立 | 当前缺少域名、ICP 与控制台资格证据 |

海外 HTTP 200、平台写有“全球 CDN”、或一次大陆截图，都不能单独证明“中国大陆稳定可用”。只有多地区、多运营商、多时段的真实测试能够改变“未验证”状态。

## 1. GitHub Pages：保留公开基线

GitHub Pages 继续承担以下角色：

- 保存一个目前可公开访问的 HTTPS 入口；
- 作为 EdgeOne 镜像测试的同版本对照组；
- EdgeOne 条件不成立或测试失败时提供回退。

GitHub Pages 支持从仓库发布静态网站和绑定自定义域名，但官方资料没有承诺中国大陆境内 CDN 或大陆稳定性，因此不把它定义为中国大陆解决方案。

- [GitHub Pages 官方文档](https://docs.github.com/en/pages)
- [GitHub Pages 自定义域名](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site)

## 2. EdgeOne Pages（Makers）：条件式首选镜像实验

### 为什么优先实验

EdgeOne Pages 支持导入 Git 仓库、自动构建、免费 HTTPS 和自定义域名；官方域名规则还明确区分“中国大陆 / 全球（含中国大陆）”与“全球（不含中国大陆）”的访问边界。这使它比一般海外免费静态托管更适合做受控的大陆访问实验。

### 免费阶段不是永久承诺

官方当前将免费阶段描述为限时免费，商业版价格尚未公布。因此：

- 不写“永久免费”；
- 不开启自动付费或升级；
- 一旦控制台要求付费、绑卡、自动续费或商业套餐，立即停止并回到审批；
- 当前免费配额仅作为实验容量参考：最多 40 个项目、每月 500 次构建、1 个并发构建、单次构建最长 20 分钟、单项目 20,000 个文件、单文件最大 25 MB、项目总存储 5 GB、最多 200 个自定义域名，并提供免费 SSL。

证据：

- [EdgeOne Pages 价格与套餐](https://pages.edgeone.ai/document/pricing-and-plans)
- [EdgeOne Pages 限制与配额](https://pages.edgeone.ai/document/limits-and-quotas)
- [EdgeOne Pages 免费证书：90 天、自动续期、无 SLA](https://pages.edgeone.ai/document/apply-for-free-certificate)

### 默认域名不能当正式大陆入口

根据官方域名说明：

- **中国大陆或全球（含中国大陆）项目**：系统生成的预览 URL 有效期为 3 小时，过期后返回 401；
- **全球（不含中国大陆）项目**：系统默认项目域名和部署域名从中国大陆访问会返回 401；
- 因此，无论选择哪个区域，稳定公开入口都必须使用自定义域名，不能把默认域名当作正式网址。

证据：

- [EdgeOne Pages 域名概览](https://pages.edgeone.ai/document/domain-overview)
- [EdgeOne Pages 自定义域名](https://pages.edgeone.ai/document/custom-domain)

### 自定义域名、ICP 与实名边界

- 选择**全球（不含中国大陆）**时，自定义域名不要求 ICP，但仍属于跨境访问实验，不能据此承诺大陆稳定。
- 选择**中国大陆**或**全球（含中国大陆）**时，自定义域名需要有效 ICP 备案；备案主体、账号实名、域名持有人和网站实际经营主体的适配性必须核实。
- 当前工作区没有自定义域名、有效 ICP 备案、合适实名账号或可选中国大陆区域的证明，因此现在不能直接得出“可在大陆境内稳定上线”。
- 若只有日本主体，能否以现有主体、个人身份或其他安排完成合规接入，必须由实际接入商及必要的合规专业人士确认；不得为了上线借用他人实名、备案或域名。
- 腾讯云要求使用中国境内云产品的账号完成实名认证；账号和资源归属以实名信息为准。企业经营活动不得用不匹配的个人实名规避主体要求。

证据：

- [工信部《非经营性互联网信息服务备案管理办法》](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)
- [腾讯云实名认证说明](https://cloud.tencent.com/document/product/378/3629)
- [腾讯云个人与企业实名认证边界](https://cloud.tencent.com/document/product/378/10495)

## 4. 可安全实施的同产物镜像预案

只有在用户批准创建实验、并提供合法可控的账号和域名后，才执行以下步骤：

1. **保持单一内容源**：GitHub 仓库和一个批准 commit 是唯一来源；GitHub Pages 与 EdgeOne 部署完全相同的静态产物，不在两个平台分别改文案。
2. **保留现有主入口**：测试期间不切换根域名、不删除 GitHub Pages。EdgeOne 使用类似 `cn-test.<自有域名>` 的测试子域名。
3. **避免搜索重复**：测试镜像添加 `noindex, nofollow`，并把 canonical 指向当前主入口；切换主站前重新审批 canonical、robots 与 sitemap。
4. **不收集真实资料**：测试镜像不启用真实联系表单、不保存个人信息、不接入来历不明的代理、统计脚本或共享 CDN。
5. **按条件选区域**：无 ICP 时最多测试“全球（不含中国大陆）”的跨境访问；只有 ICP、实名、域名与主体条件均成立，且免费账户控制台确实可选时，才测试中国大陆或全球（含中国大陆）区域。
6. **自动部署受控**：只允许主分支中已批准版本，或单独的 approved-release 分支触发；禁止把尚未批准的新文案、价格、邮箱或新版页面自动公开。
7. **可回退**：EdgeOne 失败时删除或停用测试 DNS 记录，GitHub Pages 入口保持不变。任何 DNS 变更前先记录原值和 TTL。

## 5. 真实中国大陆测试矩阵

### 样本设计

| 维度 | 最低覆盖 |
| --- | --- |
| 地区 | 北京、上海、广州或深圳、成都或重庆 |
| 运营商 | 中国移动、中国联通、中国电信 |
| 网络 | 手机数据；条件允许时增加家庭宽带 |
| 时间 | 工作日白天、工作日晚间、周末，至少持续 2 周重复 |
| 终端 | Android Chrome、iPhone Safari、微信内置浏览器 |
| 页面 | `/`、`/?lang=ja`、`/?lang=en`、`/?lang=zh` |
| 对照 | GitHub Pages 与 EdgeOne 的同一静态产物；分别记录冷启动与再次访问 |

每次记录：日期时间、城市、运营商、网络类型、设备与浏览器、DNS 是否解析、TLS 是否成功、HTTP 状态、首屏和字体/图片/CSS/JS 是否完整、三语言切换、首次可见时间、可交互时间、告警或拦截、截图；失败样本尽量保存 HAR 或浏览器网络记录。

VPN、代理、海外云服务器 `curl`、供应商控制台测速，均不能代替大陆真实用户网络样本。

### 内部实验通过线（不是对外 SLA）

- 至少完成 **36 次中国大陆冷启动加载**，覆盖上述地区与三大运营商；
- 完整渲染成功率不低于 **95%**；
- 不得在同一“城市 × 运营商”组合中重复出现 DNS、TLS 或完全打不开故障；
- 成功样本中至少 **90% 在 5 秒内显示 Hero**，并在 **10 秒内可交互**；
- 两周重复测试没有明显晚间或周末退化。

即使达到上述线，也只能表述为“在本次样本和时段中通过测试”，不得宣传为全国、永久或保证稳定。

## 6. 停止条件

出现以下任一情况，停止迁移、绑定或公开测试，并回到用户审批：

- 用户尚未明确批准创建 EdgeOne 实验，或没有合法可控的账号、自定义域名；
- 试图把 EdgeOne 默认域名当长期大陆网址，忽略“3 小时预览 / 过期或大陆访问返回 401”的限制；
- 没有 ICP，却准备选择中国大陆或全球（含中国大陆）区域；
- 实名账号、域名持有人、ICP备案主体、网站实际经营主体不一致或适用性未确认；
- 个人实名或个人备案是否适合商业品牌网站仍有疑问；
- 免费账户控制台实际上不提供中国大陆区域或所需能力；
- 平台从限时免费转为付费、要求绑卡、开启自动扣费或升级套餐；
- 大陆真实测试达不到内部通过线，或出现持续的 DNS、TLS、资源丢失、微信拦截；
- 两个平台出现内容漂移、错误 canonical、索引重复、未经批准的文案/价格/联系方式被公开；
- 测试需要收集真实客户资料，或要求使用来历不明的代理、共享中转域名、借用备案或实名。
