# 服务测试卡与报价逻辑

## 文件状态

- **用途**：内部客户访谈、报价核算和付费测试；
- **状态**：经营假设，尚未通过真实订单验证；
- **禁止用途**：未经用户逐部分批准，不直接写进公开网站，不作为固定价格承诺；
- **共同原则**：价格必须同时通过客户价值、工作范围、真实工时、外部成本和风险五项检查。

当前文件中的“被发现、被理解、被信任、被体验”只是内部诊断视角，尚未获得创始人确认为公开方法论，也未被真实客户访谈验证。目标地区、行业、客户问题和服务顺序同样属于待验证假设，不能代表全部日本商家或中文使用者。

本文件所说的“文化真实性”不等于存在一个不可改变的文化本质。当前工作定义是：以客户确认的经营事实、价值和文化背景为依据，针对具体中文使用场景重新组织表达；不得替客户推断事实、夸大历史、制造刻板印象或为了传播效果改写关键规则。这个定义仍需创始人确认后才能进入公开文案。

## 统一报价与利润口径

### 订单现金贡献

```text
不含消费税的净服务收入（折算CNY）
- 预计外部直接成本
- 预计获客成本
- 支付、银行与换汇费用
= 预计订单现金贡献
```

### 订单经济贡献

```text
预计订单现金贡献
- 预计创始人工时 × 创始人小时成本
= 预计订单经济贡献
```

“订单经济贡献”用于判断一单是否值得做，不等于公司最终净利润；它仍未必包含期间固定管理成本、退款坏账准备和税费。年末目标继续使用独立口径：

```text
期间现金净利润
= 全部实际到账收入
- 全部实际支付业务成本
```

税费是否计入用户的正式目标、以及日本消费税和所得税的处理，必须由经营主体信息和专业人士确认。台账应同时保留订单经济贡献与期间现金净利润，不能互相替代。

### 当前内部检查线

以下均为待验证经营规则：

- 订单现金贡献率低于65%：必须重新检查范围、价格或外部现金成本；这个指标不能代替工时检查；
- 低价与对应工时下的订单经济贡献率低于50%：必须缩小范围、降低工时、锁定外包成本或提高价格；
- 订单经济贡献小于0：不得按原报价出售；
- 工时无法估算：先卖诊断，不直接报完整项目；
- 客户要求保证流量、排名、粉丝、到店或销售：不进入结果保证合同；
- 第三方平台费、广告费、KOL/KOC费、差旅、印刷、摄影、认证和税费默认单列。

65%与50%都不是行业事实，只是为了给返工、管理和汇率误差保留空间的内部压力线。每完成一笔真实订单，用实际工时、支付费用、外部成本和实际到账修正。

通用价格底线可用下式压力测试，但正式报价仍需考虑客户价值与市场接受度：

```text
最低净服务收入
≥（直接外部成本 + 获客分摊 + 支付/换汇费 + 工时 × 小时成本）
÷（1 - 内部目标经济贡献率）
```

### 税与结算基准

- 公开参照混有“含税”“税别”和未注明税口径，不能直接放在同一税基比较；
- 澜顷内部压力测试统一按“不含消费税的净服务收入”计算；正式报价必须显式写明税込或税别；
- 消费税、支付手续费、银行费、换汇费和第三方平台费分开记录；
- 实际经营结果以到账、实际支付和选定的会计税务口径为准；本文件不提供税务意见。

## O-01 付费诊断 / 中国市场沟通准备包

### 客户任务

在花钱翻译、开账号或持续运营前，先知道中文使用者在哪里无法找到、理解或正确体验店铺，以及什么应该优先处理。

### 适合对象

- 已出现中文询问或中国游客到店，但问题分散；
- 不确定应该先做菜单、到店说明、平台还是内容；
- 愿意提供真实材料和一名最终确认人。

### 建议测试范围

1. 一次60–90分钟访谈；
2. 检查客户提供的现有网页、菜单、SNS和店内说明；首轮范围假设为最多5个网页、1份不超过10页的菜单、1个SNS账号最近20条内容和最多5份店内说明；
3. 按“被发现、被理解、被信任、被体验”整理信息断层；
4. 输出最多3个优先问题、材料缺口和下一步范围；
5. 一次30分钟交接说明。

### 交付物

- 《跨文化沟通与到店体验诊断》1份；
- 材料与事实确认清单1份；
- 优先级与下一步建议1页；
- 若适合继续：一份有范围的后续报价，不免费制作完整方案。

### 客户必须提供

- 官方网站、菜单、SNS和预约链接；
- 营业、价格、支付、预约、取消、拍摄、礼仪等真实规则；
- 最近出现的中文询问或误解实例（可匿名）；
- 一名可以确认事实的负责人。

### 周期与修改

- 材料齐全后5个工作日内交付为测试目标；
- 包含1轮事实纠正；
- 新增材料或重新定义问题需重新排期。

### 验收标准

- 所有发现都能对应客户材料或访谈事实；
- 明确区分事实、推断、未知和不可承诺事项；
- 客户可以据此决定“继续什么、暂时不做什么”。

### 不包含

- 完整翻译、视觉设计、账号注册、发布、广告投放；
- 法律、税务、医疗、食品安全或平台认证意见；
- 任何流量或收入预测保证。

### 测试价格与经济性

- **窄范围配对**：50,000日元，对应总工时不超过5小时；
- **扩展配对**：60,000日元，对应总工时不超过7小时；
- **外部成本假设**：0或极低；
- **内部条件**：不能把50,000日元与7小时自由组合；超出材料上限或预计超过7小时则缩小检查范围、增加阶段或提价；
- **首先验证**：客户是否愿意为问题定义和优先级付费，而不是只购买免费提案。

### 转入下一服务的条件

诊断确认存在具体信息断层、客户材料可得、负责人愿意确认事实，并且后续工作可以固定范围。

## O-02 本地化与到店信息包

### 客户任务

让中文使用者在来店前和到店中，能准确理解菜单、预约、支付、拍照、取消、点单和礼仪等关键规则，减少可预防的误解。

### 适合对象

- 已经有明确中文客流或咨询；
- 主要问题发生在来店前、点单或店内体验；
- 现有机器翻译无法承载店铺语气、文化背景或操作信息。

### 建议测试范围

为了避免“翻译全部资料”失控，首个测试包只选一个主要来店流程：

1. 最多3,000个日文字符的源内容整理与简体中文本地化；
2. 从预约、到店、点单、支付、拍摄、取消、礼仪中选择最多6个主题；
3. 一份A4或移动端单页《中国游客到店指南》；
4. 最多8条店内短提示语；
5. 术语、店名、产品名和不可翻译项清单。

数量上限是当前建议测试值，必须在报价中按实际材料重新确认。

### 交付物

- 日中对照内容表；
- 可交给设计或网页人员使用的简体中文成稿；
- 一页到店指南的文字版；
- 店内提示语清单；
- 客户事实确认记录。

### 客户必须提供

- 最新、可编辑的日文原文和价格；
- 图片、菜单、预约和支付规则；
- 品牌语气、专有名词和禁止表达；
- 食材、过敏、取消和拍摄等关键事实的负责人确认。

### 周期与修改

- 材料齐全后10–15个工作日为测试目标；
- 包含2轮汇总反馈：事实确认1轮、表达调整1轮；
- 原文、价格、规则或范围变化触发变更单。

### 验收标准

- 与客户确认的日文事实一致；
- 数字、价格、时间、地址、过敏、支付和取消信息经过单独检查；
- 中文读者无需猜测即可完成所选来店流程；
- 交付格式能被客户实际放入网页、菜单或店内资料。

### 不包含

- 印刷、网页开发、视觉排版、摄影、额外语言；
- 法律文件或需要专业资质的翻译认证；
- 客户未提供事实的补写；
- 平台账号运营或发布。

食材、过敏、医疗、法律、支付和取消等高风险内容不能只依赖客户口头确认。若创始人的相应语言复核能力或专业边界尚未确认，报价必须增加合格中文复核成本，或把这些内容明确排除；客户事实确认不能代替语言质量控制和专业意见。

### 测试价格与经济性

- **窄范围配对**：120,000日元，对应总工时不超过12小时；
- **扩展配对**：200,000日元，对应总工时不超过24小时；
- **外部成本假设**：校对、设计、印刷或摄影如需使用必须单列；
- **内部条件**：不能把120,000日元与24小时自由组合；新增高风险复核、设计或其他外部成本后必须重新核算；
- **首先验证**：商家是否愿意为“可执行的到店流程”付费，而不仅是按字数购买翻译。

### 升级路径

实际使用后再决定是否增加网页实施、菜单扩展、更多店内触点或平台内容，不默认打包。

## O-03 中国平台启动包

### 客户任务

在账号归属、认证、素材和表达责任清楚的前提下，建立一个可以由客户继续管理的中国平台基础，而不是只创建一个空账号。

### 进入条件

- 已完成诊断或等效的信息整理；
- 已确认目标平台适合客户，而不是因为“大家都在做”；
- 客户可以合法提供账号主体、手机号、认证材料和素材授权；
- 客户接受平台审核、算法和账号状态不可保证。

正式启动内容制作前先完成账号可行性与材料齐备门。账号、手机号、双重验证和长期凭证始终由客户持有；澜顷不持有客户长期密码。若认证或主体条件不成立，先交付可行性记录、缺失材料和可选路径，再按报价中的阶段条款暂停或终止；平台和第三方已经收取的费用按其规则处理，服务费可退与不可退范围必须随阶段写入报价。

### 建议测试范围

1. 一个平台；
2. 账号资料与权限清单；
3. 简介、定位、关键词和内容栏目；
4. 首批4条内容的日文/中文结构确认与简体中文成稿；报价中必须定义每条的文字长度、图文/视频类型、图片数量和视频处理边界；
5. 一个月内容日历；
6. 发布与账号交接说明。

### 交付物

- 账号启动检查表；
- 账号定位与栏目说明；
- 4条首发内容包；
- 30天内容日历；
- 账号、文件与权限交接记录。

### 客户必须提供

- 真实主体和平台要求的认证材料；
- 可用于平台的照片、视频、商标和店铺信息；
- 一名日文事实确认人；
- 账号持有手机号、设备和必要操作配合。

### 周期与修改

- 资料与账号条件齐全后4–6周为测试目标；
- 每条内容先确认日文结构，再制作中文；
- 包含2轮汇总修改；
- 平台审核等待时间不计入可控交付承诺。

### 验收标准

- 账号和权限归属有书面记录；
- 所有内容与客户确认事实一致；
- 4条内容和日历按约定格式交付；
- 客户知道后续自行管理或继续委托需要做什么。

### 不包含

- 认证必然通过、账号长期存续、粉丝或曝光保证；
- 广告费、KOL/KOC费、平台费、第三方认证费；
- 原创拍摄、无限素材制作、额外平台；
- 日常DM/评论和持续运营。

### 测试价格与经济性

- **基础配对**：250,000日元，对应总工时不超过30小时；
- **扩展配对**：350,000日元，对应总工时不超过40小时；
- **外部成本假设**：认证、设备、拍摄、设计和第三方费用全部单列；
- **内部条件**：不能把250,000日元与40小时自由组合；账号可行性、认证协作和内容制作按阶段核算，外部费用出现后必须重算；
- **首先验证**：客户是否为“可继续管理的账号与首批内容系统”付费，以及认证协作实际消耗多少工时。

## O-04 单平台持续内容运营

### 当前建议

不作为第一项主推服务。至少先有2个与内容制作相关的付费交付及真实工时记录，再完成1个按月付费试运行并记录续费或不续费原因，才考虑标准化出售。

### 客户任务

在一个中国平台上持续输出准确、可确认、符合店铺实际体验的内容，并按月复盘可控指标。

### 建议最小月度范围

1. 一个账号、一个平台；
2. 每月一次选题与素材会议；
3. 客户提供素材基础上的4–6条内容；报价中逐类限定图文/视频、文字长度、图片数量和基础处理范围；
4. 日文结构确认后制作简体中文；
5. 发布排期或按合同约定发布；
6. 一份月报与一次复盘。

DM、评论、原创拍摄、广告、达人和危机处理默认不包含，因为工作量不可预测。

### 交付物

- 月度内容日历；
- 4–6条内容包；
- 发布记录；
- 一份月度数据与学习报告；
- 下一月调整建议。

### 客户必须提供

- 每月按时提供可用素材和最新经营信息；
- 在约定时间内确认日文结构；
- 及时通知价格、营业、预约、活动和规则变化；
- 指定唯一确认人。

### 周期与修改

- 先做1–3个月付费试运行，每月为一个交付周期并按月预付；
- 每条内容包含1轮结构确认和1轮事实/表达汇总修改；
- 客户延迟确认导致的发布顺延需记录；
- 默认不自动续约；续约、暂停、取消窗口和未用额度处理以书面报价为准。

### 验收标准

- 约定数量按批准内容交付或发布；
- 事实、授权与发布记录完整；
- 月报只报告可验证数据，不把曝光直接解释为到店或销售。

### 不包含

- 结果保证、全天候客服、无限评论私信；
- 原创拍摄、达人、广告、额外语言或平台；
- 平台故障、审核、封禁和算法变化的结果责任。

### 测试价格与经济性

- **客户供素材窄范围配对**：120,000日元/月，对应总工时不超过15小时；
- **轻制作配对**：160,000日元/月，对应总工时不超过20小时；
- **较多制作配对**：230,000日元/月，对应总工时不超过28小时；
- **扩展范围原则**：增加原创制作、8–12帖、日常管理或报告深度后，必须重新估算，不能简单按帖加价；
- **首先验证**：素材等待、客户确认、中文制作、发布和报告的真实月度工时，以及客户是否续费。

## 推荐验证路径

```text
同一细分客群的真实客户访谈
→ O-01 付费诊断或已有的等效诊断
→ 按具体问题分流至 O-02 本地化 / O-03 平台启动
→ 有真实工时与续费证据后才进入 O-04 持续运营
```

### 为什么不先卖“全套中国市场运营”

- 账号、内容、到店信息、平台费用和拍摄的成本结构不同；
- 新业务没有足够真实工时与续费数据；
- 全套方案容易形成范围失控和结果保证预期；
- 先解决具体、可验收的信息问题，更容易得到付款证据和案例授权。

## 每个服务的验证门

| 验证项 | 继续标准 | 未达到时 |
| --- | --- | --- |
| 重复问题 | 同一ICP、同一问题的10次访谈中至少3次出现相同具体问题 | 更换问题或客户段，不继续润色套餐 |
| 付款意愿 | 每个拟标准化服务分别获得至少2个真实付费测试 | 检查客户、价值和范围，不用点赞或口头兴趣代替，不混算不同业态和服务 |
| 交付经济性 | 实际订单经济贡献为正，且订单现金贡献率和经济贡献率达到内部压力线 | 缩小范围、提价、标准化或停止 |
| 可控性 | 关键交付不依赖无法控制的平台结果 | 改成交付物承诺或放弃 |
| 证据 | 客户确认交付有用；公开证据需另有书面授权 | 只内部学习，不公开案例 |
| 可重复性 | 两个项目的输入、步骤与验收可以复用 | 继续作为定制项目，不包装成标准服务 |

访谈还必须记录客户当前替代方案、实际预算、决策人、采购周期和材料供给能力；只验证“有痛点”并不能证明会成交。O-04除上述共同验证门外，还必须满足：2个相关内容交付的真实工时记录、1个按月付费试运行，以及明确的续费或不续费原因。

## 年末目标的容量门

这些单价本身不能证明2026年末10万元人民币净利润目标可达。每周必须用经营台账更新：

```text
剩余可售工时
= 剩余周数 × 每周可投入工时 × 可用于交付的比例

预计到账
= 各服务合格商机数 × 报价率 × 成交率 × 平均净服务价 × 年内回款率
```

在没有真实的每周工时、销售转化、交付工时和回款周期前，只能做保守/基准/压力情景，不能承诺年末结果。所有情景以真实到账和实际支付成本滚动替换假设。

## 报价语言边界

可以承诺：

- 按确认事实制作约定交付物；
- 在客户按时提供材料和反馈的条件下遵守可控周期；
- 记录、检查、交接和复盘；
- 发现未知和风险时及时提出。

不能承诺：

- 必然被搜索到、获得推荐、增长粉丝或形成到店；
- 平台认证、账号存续、审核和算法结果；
- 客户未确认的经营事实、法规或专业结论；
- 中国市场“整体成功”。
