# 首批访谈外联与回复处理草稿

## 文件状态

- 版本：v0.1（2026-08-21）
- 用途：把公开资料研究转成可由创始人逐封审核的访谈邀请
- 当前状态：内部草稿，未发送，未获得任何商家同意
- 对象状态：A-01、A-02、A-03 均为未联系、未验证、非客户
- 禁止动作：未经创始人确认签名身份、回复邮箱、可访谈时间并明确批准具体对象，不得发送、填写表单、致电或私信

这不是群发营销模板。每一封只验证一个问题：商家是否实际遇到中文使用者在预约、来店前信息或现场规则上的问题。对方回答“没有”“现有方式足够”同样是有效结果，不继续推销。

## 商业目的与法律风险提示

这不是学术或中立调查。真实目的是：在形成面向福冈地区商家的中文来店前信息与体验内容整理服务之前，验证是否存在具体、重复且值得付费解决的问题。对外必须如实披露“正在验证小规模商业服务”，不能只说“正在调查”。

日本消费者厅关于《特定电子邮件法》的公开资料说明：广告宣传邮件原则上实行事前同意；公开营业邮箱存在例外，但若邮箱同时明确拒绝广告宣传邮件，则不能依赖该例外；广告宣传邮件还涉及发送者和拒收方式等表示义务。参见[消费者厅说明](https://www.caa.go.jp/policies/policy/consumer_transaction/specifed_email/pdf/specifed_email_180709_0001.pdf)。

本文件采用比“可能允许”更保守的执行线：用途不明的预约、售后或消费者咨询表单不用于陌生开发；页面写有 `営業メールお断り`、用途限定或同类拒收说明时不发送。实际发送前，仍需根据真实发送主体、内容和渠道向日本适用专业人士确认；本文件不是法律意见。

## 发送前共同检查

以下任一项为空，都不得发送：

- [ ] 创始人确认可以公开使用的姓名或称呼
- [ ] 可以接收回复的真实邮箱
- [ ] 可以进行日语访谈的人及真实日语能力
- [ ] 未来 14 天内可提供的 3 个访谈时段
- [ ] 已重新打开对象官网，确认事实和联系入口在最近 30 天仍有效
- [ ] 已检查联系页、利用条款和邮箱旁说明；不存在 `営業メールお断り`、用途限定或其他拒收商业联络的表示

- [ ] 没有承诺免费完整诊断、中文样稿、流量、到店或销售结果

- [ ] 已为该对象建立唯一线索编号和下一动作日期

## 免费访谈的边界与开场

15 分钟访谈只听取现状并判断是否适合继续，不审查完整菜单或网站，不提供定制诊断、中文样稿、书面改进方案、逐页建议或平台账号方案。访谈后的免费邮件只包含感谢、事实核对和下一步许可，不附带免费诊断。

### 日语开场草稿

```text
本日はお時間をいただき、ありがとうございます。

最初に確認ですが、本日は現在の状況を伺い、現在検討している支援サービスと合う課題があるかを確認するための15分ほどのヒアリングです。この場で契約をお願いしたり、無料の診断や制作を行ったりするものではありません。

録音は行わず、サービス設計のための内部メモのみ作成します。お客様個人のお名前、連絡先、注文情報などは伺いません。メモに残してほしくない内容があれば、その場でお知らせください。貴社名やお話の内容を外部で使用する場合は、別途書面で許可をお願いします。
```

访谈结束前只问一次许可：

```text
本日伺った内容を整理し、もし有償でお手伝いできる小さな範囲がありそうな場合、作業内容と費用を記載したご案内を後日お送りしてもよろしいでしょうか。
```

对方不同意时，只发送感谢和事实核对，关闭销售下一步。

### 访谈笔记与删除规则

- 只记录验证服务所必需的最少信息：商家名称、业务联系人姓名与职位、问题事实、当前处理方式、影响、下一步许可；
- 不收集游客姓名、联系方式、订单、健康或支付等个人信息；对方主动提及时，不把可识别个人的信息写入笔记；
- 未经单独书面授权，不把商家名称、可识别原话、截图或结论转成案例、证言或网站内容；
- 访谈结束 90 天后，若没有进入双方同意的后续流程，删除联系人姓名、职位和可识别原话，只保留去标识化的验证结论；
- 对方之后要求删除时，在 7 个自然日内删除可识别笔记；若对方要求停止联系，只保留执行永久停止所需的最少拒收记录；
- 若进入报价或项目，保留期限、访问权限与删除方式需在正式文件中重新确认，不能无限期沿用访谈阶段规则。

## 从访谈进入 O-01 的资格门

以下全部满足，且对方明确允许另发付费诊断说明，才能准备 O-01：

- [ ] 问题是真实、重复并带来时间、误解或经营成本，不只是我们的假设
- [ ] 访谈对象是决策人，或能引入最终决策人与事实确认人
- [ ] 有可编辑材料和唯一确认人
- [ ] 接受 O-01 是付费、固定范围且不保证经营结果
- [ ] 预算可能性和时间窗口基本匹配
- [ ] 不要求免费样稿、完整方案、虚构案例或违规账号操作
- [ ] 过敏、法律、平台认证等高风险事项可由专业人士复核或排除范围

任一关键门不满足，只记录访谈学习，不进入报价。只有独立书面报价列明价格、输入上限、交付物、验收、修改、不包含、周期和付款条件，并在客户书面接受且约定款项到账后，才开始审材料或制作。

## 回复分流

### 1. 同意访谈

```text
ご返信ありがとうございます。

それでは、15分ほど、現在のご状況を中心に伺えればと思います。事前資料は不要です。

下記の候補はいかがでしょうか。
・[候補日時・日本時間 1]
・[候補日時・日本時間 2]
・[候補日時・日本時間 3]

方法は[お電話 / オンライン]のうち、ご都合のよいものをお知らせください。録音は行いません。

お話の内容や貴社名を許可なく公開することはありません。
```

动作：建立线索和访谈编号；以笔记方式记录对方原话、职位、同意的时间与方式；不录音，不在确认邮件里发送报价。

### 2. 直接询问服务或价格

```text
お問い合わせありがとうございます。

現在はサービス内容を検証している段階で、料金はまだ確定していません。内容により必要な作業が異なるため、まずは現在の状況を15分ほど伺っています。

具体的に困っている場面、現在の対応方法、必要な資料や確認体制を伺ったうえで、対応可能な範囲かを双方で確認できればと思います。対応可能で、別途ご案内する許可をいただいた場合のみ、作業範囲・納品物・修正回数・費用・含まれない事項を明記してご案内します。
```

动作：不得直接发送 Complete 或长期运营套餐；先通过需求门和报价前检查。

### 3. 表示目前没有需要

```text
ご返信ありがとうございます。現在は必要がないとのこと、承知いたしました。

お時間を取ってご回答いただき、ありがとうございました。こちらから追加のご連絡はいたしません。
```

动作：记录“无当前需要”及对方原话，停止推进，不用说服。

### 4. 要求案例或业绩

只有在“服务仍在验证阶段，且确实没有可介绍的交付案例”仍属实时事实时使用：

```text
本サービスは現在検証段階で、まだご紹介できる納品事例はありません。

ご検討いただける場合は、事前に作業範囲と確認基準を決め、対象と納品物を絞った小さな案件から始める形を考えています。
```

动作：不得把占位案例、研究对象、试做稿或未授权项目变成案例。

### 5. 要求保证流量、预约、到店或销售

```text
恐れ入りますが、閲覧数、検索順位、フォロワー数、予約数、来店数、売上などの結果を保証することはできません。

また、プラットフォームの審査、アカウント認証、アカウントの継続、アルゴリズム上の表示も保証できません。

お約束できるのは、書面で事前に合意した範囲の調査や制作物、確認方法、修正回数までです。結果保証が前提となる場合は、今回はお引き受けできません。
```

动作：如果结果保证是合作前提，记录后停止，不通过降价或扩大免费范围换取成交。可承诺内容仅限书面报价中双方确认的交付物、流程和修改轮次。
