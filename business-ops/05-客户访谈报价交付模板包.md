# 客户访谈、报价、交付与回款模板包

> 版本：v1.0（2026-08-21）
> 状态：内部可填写模板；对客户发送前必须逐项确认
> 适用范围：日本本地商家面向中文使用者的内容、本地化、到店体验信息与中国平台准备工作

## 先读这页

这套模板把“找到客户 → 判断是否适合 → 报价 → 收款 → 交付 → 验收 → 复盘”串成一条可执行路径。它不是法律合同、税务意见或平台官方意见。涉及经营主体、跨境收款、税务、商标、个人信息、食品与过敏信息、广告合规或平台认证时，应根据项目实际情况获得合格专业人士或平台官方确认。

### 绝对不能省略的四道门

1. **需求门**：没有具体问题、决策人、时间窗口和客户材料，不制作完整方案。
2. **报价门**：没有范围、交付物、客户输入、修改轮次、成本与不包含事项，不发报价。
3. **现金门**：合同或书面委托、订金和关键材料未到位，不正式排期。
4. **证据门**：没有书面授权，不公开客户名称、Logo、数据、截图、评价或项目结果。

### 使用顺序

| 阶段 | 使用表单 | 完成后做什么 |
| --- | --- | --- |
| 筛选线索 | A. 线索筛选卡 | 不合格则停止或培养；合格则预约访谈 |
| 了解问题 | B. 客户问题访谈记录 | 复述问题并确认是否进入付费诊断或报价 |
| 收集输入 | C. 付费诊断 / 项目输入表 | 判断材料、权限、风险与工作边界 |
| 内部核价 | D1. 报价前内部检查 | 通过贡献率、产能和风险门后才对外报价 |
| 对外报价 | D2. 报价与工作范围模板 | 客户书面确认并按条件付款 |
| 启动交付 | E. 启动与材料接收表 | 建项目编号、版本和唯一确认人 |
| 控制进度 | F. 交付计划与确认记录 | 逐阶段确认事实、语言和版本 |
| 处理新增 | G. 变更单 | 未确认新增费用和时间前不扩展工作 |
| 完成项目 | H. 验收与交付记录 | 获得书面验收并处理尾款 |
| 结账复盘 | I. 回款与项目复盘 | 把真实收入、成本和工时录入台账 |
| 对外证明 | J. 案例与证据授权 | 未单独授权则默认不公开 |
