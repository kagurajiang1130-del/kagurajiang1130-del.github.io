# 网站内容访谈记录

## 使用方式

- 当前一次只回答一个 Part；具体问题由访谈 Agent 在对话中生成。
- 不需要商业术语，也不需要把话说得完整或漂亮。
- 可以逐题回答，也可以想到哪里说到哪里。
- 在用户看到完整结果并明确批准之前，本文件不会写入访谈原话或提炼结果。
- 批准后，归档 Agent 会把原意和加工结果分开保存；不会把营销语言冒充为你的原话。
- 如果某个答案暂时没有，可以写“不知道”“以后再想”或举一个具体场景。

## Part 01：为什么这个品牌应该存在

**状态：访谈中**

这一 Part 不急着取品牌名，也不要求用户自己写广告语。访谈 Agent 会围绕“为什么值得做、怎样才算被理解、不愿成为怎样的品牌、希望关系发生什么改变”设计 2–4 个问题。

### 当前保存状态

尚未保存任何 Part 01 访谈回答、提炼结果或公开文案。

访谈回答后，工作链会先在对话中展示：

- 用户原意与语义锚点；
- 事实、编辑推断、未知和不可使用内容；
- 客户可以感受到的价值；
- 对应 `brand` / `hero` / `philosophy` / `vision` 的网站成稿；
- 独立审稿结论；
- 获得批准后计划写入的文件与章节。

只有用户明确批准当前展示版本后，归档 Agent 才会把上述内容写到这里。
